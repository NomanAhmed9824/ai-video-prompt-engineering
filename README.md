## My Prompt Engineering Framework

1. **Identity Lock First** — Character/product description is fixed
2. **One Clear Action** per clip
3. **Camera Language** — Shot type + movement always specified
4. **Lighting Control** — Direction, color temperature, intensity
5. **Realism Details** — Skin texture, natural imperfections, lens characteristics
6. **Iterate & Document** — What failed and why
